# MantisBT : Privatus

Usage : ``python -c "COOKIE"``

Any authenticated **manager** can fully use this however, any **other** role can only use the ``second exploit`` which can be use to chain another exploit 



### Before Running :

Configure the following

	- host
	- minIssueId or you can leave the default value
	- maxIssueId or you can leave the default value



### First Exploit - Disclosure of private project name (CVE-2020-29603)



> Read [more](https://mantisbt.org/bugs/view.php?id=27727)

Any authenticated **manager** can disclosed the ``private project name`` due to fact that the ``private project name`` will render on navbar. 

**Note : ** If you are authenticated using any other **role** (reporter - viewer) and used this exploit, this will only return your ``username/name``.



### Second Exploit - Disclosed the Status and Summary of a Private Issue (CVE-2020-29605)



> Read [more](https://mantisbt.org/bugs/view.php?id=27727)

Any authenticated user can disclosed the the **status** and **summary** of any private issues.



### Third Exploit - Full disclosure of private issue contents, including bugnotes and attachments (CVE-2020-29604)



> Read [more](https://mantisbt.org/bugs/view.php?id=27728)



The first and second exploit allows you to disclose just the ``summary,status, and project name`` (for authenticated manager) however on this third exploit it allows you to fully disclose the issue, this includes the bugnotes and attachments. You can use any ``proxy`` to use this exploit and **manually** copy the issue.



1. The first/second exploit works

   

2. Modify the ``haveProxy`` to ``True``

   

3. Resend again the exploit

   

4. Go to your proxy (I tested this on Burpsuite)

   

5. Go to ``HTTP History``

   

6. Right click the ``request``

   

7. Click the ``Show the response on browser``

   

8. Copy the link that generated by Burpsuite

   

9. Visit the link

   

10. Click the Copy Issues

    

11. Go to ``/view_all_bug_page.php``

    

12. Notice on the ``Viewing issues`` section the private file will appear





You can read the full report [here](https://mantisbt.org/bugs/view.php?id=27357)
